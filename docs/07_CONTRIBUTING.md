# CONTRIBUTING

## Principes

-   Privilégier la simplicité.
-   Respecter 01_PRODUCT.md.
-   Respecter l'architecture.
-   Éviter la sur-ingénierie.

## Backend

-   Pas de logique métier dans les contrôleurs.
-   Le domaine reste indépendant.
-   Une responsabilité par classe.

## Frontend

-   Une responsabilité par composant.
-   Réutiliser les composants.
-   Garder les écrans lisibles.

## Git

Convention de commits :

    feat(...)
    fix(...)
    refactor(...)
    docs(...)
    test(...)

Une Pull Request = une fonctionnalité.
